RUTH AKKA — BIRTHDAY WEBSITE

HOW TO PREVIEW
1. Extract this ZIP file.
2. Open index.html in Chrome or another modern browser.

PHOTOS AND VIDEOS
All 13 photos and both videos are already included in the assets folder.

ADD MUSIC LATER
1. Get the MP3 audio file you are allowed to use.
2. Rename it exactly to: kalyani-whistle.mp3
3. Copy it into the assets folder (beside the photo and video files).
4. Open index.html. Tap the “Music: OFF” button to start playback.
   Browsers require a user tap before audio can play.

PUBLISH WITH GITHUB PAGES
Upload index.html and the complete assets folder to your GitHub repository.
Keep the folder structure unchanged. Then enable GitHub Pages in repository Settings > Pages.
